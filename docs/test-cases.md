# Тестовые наборы и сценарии

Документ составлен по ГОСТ 19.301-79. Проверяются три модуля и приложение
целиком. Автоматические тесты лежат в каталоге `tests/` и запускаются командой:

```bash
python -m unittest discover -s tests -t .
```
